## 🌟 Overview | نظرة عامة

**Ultra Secure Password Generator** is a high-precision, client-side web utility designed to engineer cryptographically strong, customizable passwords. Built with zero external dependencies, it ensures your sensitive data never leaves your browser window.

تطبيق ويب عالي الدقة لتوليد كلمات مرور قوية وقابلة للتخصيص بمعايير أمان عالية، ويعمل بالكامل داخل المتصفح دون إرسال أي بيانات لخوادم خارجية.

---

## ✨ Key Features | المميزات الخرافية

* **🛡️ Cryptographic Randomness:** الاعتماد على مولدات عشوائية آمنة لتوليد سلاسل نصية يستحيل توقعها.
* **🎛️ Full Granular Control:** تحكم كامل في طول كلمة المرور (من 4 إلى 128 حرفاً) وتفعيل/تعطيل (الأحرف الكبيرة، الصغيرة، الأرقام، والرموز الخاصة).
* **⚡ Instant Clipboard Action:** نسخ فوري بنقرة واحدة مع تأكيد بصري ذكي.
* **📊 Live Strength Indicator:** مؤشر تفاعلي يحلل مدى قوة وثبات كلمة المرور لحظياً.
* **📱 Responsive & Sleek UI:** تصميم عصري (Dark/Modern Theme) يتكيف بسلاسة مع كافة الشاشات والأجهزة.
* **🔒 100% Client-Side Privacy:** المعالجة تتم بنسبة 100% على جهازك، لا تخزين ولا تتبع.
